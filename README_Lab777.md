# 💻 Lab 777 — Робота з користувацькими класами (C++)

## 📄 Опис
Ця лабораторна робота присвячена створенню користувацьких класів у мові **C++**, роботі з конструкторами, деструктором, методами та перевантаженням операторів.  
Реалізовано два завдання:  
1. **Клас Fraction** — робота з раціональними дробами.  
2. **Клас TimeOfDay** — робота з часом у межах доби.
