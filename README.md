## 🎯 Мета роботи
Навчитись створювати власні класи у C++, працювати з конструкторами, деструкторами, методами та перевантаженням операторів.  
Закріпити практичні навички об’єктно-орієнтованого програмування.

## 🧩 Завдання 1 — Клас Fraction
Реалізувати клас `Fraction` для роботи з раціональними дробами.  
Передбачити методи для:
- введення та виведення дробів;
- нормалізації значення;
- перевантаження операторів `+`, `-`, `*`, `/`.

📄 **Код програми:**  
[`Fraction.cpp`](https://github.com/vvivchar-bit/-111/blob/main/Fraction.cpp)

📘 **Результат роботи:**  
Вивід у консолі з прикладами обчислень та екранним скріншотом.  
[Переглянути звіт (приклад роботи)](https://github.com/vvivchar-bit/-111/blob/main/Lab6_Vivchar_ALK43_Final_WithScreens_DejaVu.pdf)

## 🕒 Завдання 2 — Клас TimeOfDay
Реалізувати клас `TimeOfDay` для роботи з часом у межах доби.  
Передбачити методи для:
- введення та виведення часу;
- обчислення часу до півночі;
- перевантаження операторів `+` і `-` (зміна часу на певну кількість секунд).

[`TimeOfDay.cpp`](https://github.com/vvivchar-bit/-111/blob/main/TimeOfDay.cpp)
